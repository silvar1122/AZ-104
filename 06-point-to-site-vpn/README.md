
# Azure Point-to-Site VPN with VPN Gateway

## Objective

The objective of this lab is to configure a Point-to-Site (P2S) VPN connection using Azure VPN Gateway and establish secure connectivity from a Windows client to a private Azure virtual machine.

## Technologies Used

- Azure Virtual Network
- Azure VPN Gateway
- Point-to-Site VPN
- Microsoft Entra ID
- Azure VPN Client
- OpenVPN
- Azure Virtual Machine
